# España — dificultad personal (PKD) para una web nueva

Semrush, Keyword Magic Tool, base de datos España, concordancia amplia, vista
«Grupos», 14 oct 2026. Con `babybookai.com` en la casilla «Introduce dominio
para personalizar» y la columna «PKD %» activada. Leído por Claude manejando
Semrush en la ventana de JonyTools.

PKD = dificultad personalizada: lo difícil que es posicionar **esa web**
(babybookai.com, sin enlaces ni autoridad), de 0 a 100. KD = dificultad general.
Verde hasta 49, naranja 50–69, rojo desde 70. En la base española la PKD no
viene calculada: cada keyword se refrescó una a una («Actualizar»). Los
volúmenes pueden diferir de las rondas anteriores porque Semrush los actualizó.

## Lo que dice

- **Todo es rojo**: la PKD española va de 75 a 96 con un KD de 4 a 13. El KD
  «muy fácil» de las rondas 1 a 3 no se aplica a una web nueva.
- **La keyword de la página del primer año es la más difícil de todas**:
  `album bebe primer año` (140) tiene PKD 94 y `album primer año bebe` (140),
  96. Las variantes con «libro» (`libro primer año bebe`, 90, PKD 86) y con
  «fotos» (`álbum fotos bebé primer año`, 50, PKD 76) son 8 y 18 puntos más
  bajas.
- **En el álbum de fotos**, la mejor es `album de fotos para bebes` (140,
  PKD 75), 7 puntos por debajo de la actual (`album fotos bebe`, 480, PKD 82),
  con casi una cuarta parte del volumen.
- La razón probable: las SERP españolas son páginas de dominios con enlaces
  (imprentas, Amazon) y las que no tienen enlaces son tiendas con dominio
  antiguo (enblancshop.com tiene 931 dominios de referencia). El KD mira solo
  las páginas; la PKD, también el dominio.
