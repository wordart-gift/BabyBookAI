# Alemania — dificultad personal (PKD) para una web nueva

Semrush, Keyword Magic Tool, base de datos Alemania, concordancia amplia,
14 oct 2026. Con `babybookai.com` en la casilla «Introduce dominio para
personalizar» y la columna «PKD %» activada (engranaje → Administrar columnas).
Leído por Claude manejando Semrush en la ventana de JonyTools.

PKD = dificultad personalizada: lo difícil que es posicionar **esa web**
(babybookai.com, sin enlaces ni autoridad), de 0 a 100. KD = dificultad general.
Verde hasta 49, naranja 50–69, rojo desde 70. «n/d» = Semrush no la tenía
calculada; las candidatas útiles se refrescaron una a una («Actualizar»), el
resto sigue sin dato. Las keywords de menos de 90 búsquedas casi nunca la traen.

## Lo que dice

- **La PKD alemana es mucho más alta que el KD**: toda la familia «Fotobuch»
  está entre 59 y 81 (naranja y rojo) con un KD de 9 a 21. Para una web nueva
  no hay ninguna keyword verde.
- **La más baja con volumen es `baby fotobuch` (480, PKD 59)**, no la de la
  página (`fotobuch baby`, 880, PKD 67). La diferencia, 8 puntos, es pequeña.
- **En el primer año**, la keyword actual (`mein erstes jahr fotobuch`, 210) es
  de las más difíciles (PKD 81, KD 21). Las más asequibles son
  `fotobuch baby 1. jahr` (140, PKD 64) y `fotobuch baby erstes jahr` (50,
  PKD 63): 17 puntos menos.
- **«Fotoalbum» no es más fácil**: `fotoalbum baby` 73, `baby fotoalbum` 70.
